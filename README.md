# Calm Smile Studio

Create a premium, modern, elegant 4-page website for a professional dental clinic.

The website must feel trustworthy, calm, sophisticated and welcoming.

IMPORTANT DESIGN DIRECTION:

- Avoid neon colours completely.

- Avoid bright, saturated or flashy colours.

- Use ONLY a subtle, muted and sophisticated colour palette.

- Preferred palette:

  - Warm white / ivory: #FAF9F6

  - Soft sage: #A8B5A2

  - Muted blue-grey: #8FA5AE

  - Deep charcoal: #263238

  - Soft beige: #E8E2D8

- Use the colours sparingly.

- Keep backgrounds mostly white or warm ivory.

- Use muted sage or blue-grey only for accents, buttons, icons and selected sections.

- Buttons should be elegant and understated, not flashy.

- Avoid excessive gradients.

- Avoid glowing effects.

- Avoid excessive shadows.

- Use subtle borders and soft shadows.

- Use generous whitespace.

- Use premium typography with strong readability.

- The overall visual feeling should be similar to a high-end private dental clinic.

- The website should look expensive, clean and professional rather than colourful or playful.

TECHNICAL REQUIREMENTS:

- Fully responsive on desktop, tablet and mobile.

- Fast-loading layout.

- Smooth scrolling.

- Subtle animations only.

- Clean navigation.

- SEO-friendly structure.

- Accessible typography and colour contrast.

- Use high-quality professional dental/clinic imagery.

- Do not use cartoonish dental illustrations.

- Do not use cheesy stock photos.

- Use realistic, premium healthcare imagery.

GLOBAL UX REQUIREMENTS

==================================================

1. Keep "Book an Appointment" as the main CTA across the website.

2. Add a floating WhatsApp button on every page.

3. Add click-to-call functionality on mobile.

4. Use subtle hover effects on buttons and cards.

5. Use smooth fade/slide animations when sections enter the viewport.

6. Do not use excessive animations.

7. Keep the website spacious and uncluttered.

8. Use rounded corners moderately. Do not make everything excessively rounded.

9. Use professional line icons for dental services.

10. Keep the typography elegant and highly readable.

11. Use large, high-quality images with rounded corners or clean rectangular framing.

12. Avoid stock-photo clichés whenever possible.

13. Do not use neon green, neon blue, bright purple, bright red, fluorescent colours or highly saturated gradients.

14. Do not use a colourful medical-template aesthetic.

15. The final website should feel:

   - Premium

   - Calm

   - Trustworthy

   - Minimal

   - Sophisticated

   - Modern

   - Patient-friendly

16. Maintain consistent spacing, typography, buttons, cards and colours throughout all four pages.

17. Make the design look suitable for a premium private dental clinic in India.

18. Ensure every page has a clear path toward booking an appointment.

19. Make the mobile version especially polished because many dental patients will visit the website from their phones.

20. Use realistic placeholder content and images where actual clinic information has not yet been provided. Make all placeholder information easy to replace later.
